🔹 Step 1: Define the Problem
Your goal is to compare resume text with job descriptions and return a matching score (0-100). This is a text similarity problem, which requires text processing, feature extraction, and machine learning modeling.

🔹 Step 2: Data Preprocessing
Before training a machine learning model, you need to clean and process your text data.
✅ Tasks in this step:
	1	Tokenization – Convert text into words.
	2	Remove Stopwords – Remove common words (e.g., "the", "is", "and").
	3	Vectorization (TF-IDF) – Convert text into numerical format for ML.
🔹 Code: Preprocess Resumes & Job Descriptions
from pyspark.ml.feature import Tokenizer, StopWordsRemover, HashingTF, IDF, VectorAssembler
from pyspark.sql import SparkSession

# Initialize Spark
spark = SparkSession.builder.appName("ResumeAnalyzer").getOrCreate()

# Sample DataFrame
data = [
    ("Software Engineer with Python and Spark", "Looking for a Python Spark Developer", 1),
    ("Data Scientist with deep learning", "AI Engineer with ML and DL expertise", 0.9),
    ("Marketing Specialist with SEO knowledge", "SEO Expert for digital campaigns", 0.85)
]

df = spark.createDataFrame(data, ["resume", "job_desc", "match_score"])

# Tokenization
tokenizer = Tokenizer(inputCol="resume", outputCol="resume_tokens")
tokenizer2 = Tokenizer(inputCol="job_desc", outputCol="job_desc_tokens")

df = tokenizer.transform(df)
df = tokenizer2.transform(df)

# Remove Stopwords
stopword_remover = StopWordsRemover(inputCol="resume_tokens", outputCol="resume_filtered")
stopword_remover2 = StopWordsRemover(inputCol="job_desc_tokens", outputCol="job_desc_filtered")

df = stopword_remover.transform(df)
df = stopword_remover2.transform(df)

# TF-IDF Vectorization
hashingTF = HashingTF(inputCol="resume_filtered", outputCol="resume_tf")
hashingTF2 = HashingTF(inputCol="job_desc_filtered", outputCol="job_desc_tf")

df = hashingTF.transform(df)
df = hashingTF2.transform(df)

idf = IDF(inputCol="resume_tf", outputCol="resume_tfidf")
idf2 = IDF(inputCol="job_desc_tf", outputCol="job_desc_tfidf")

df = idf.fit(df).transform(df)
df = idf2.fit(df).transform(df)

df.select("resume", "resume_tfidf", "job_desc", "job_desc_tfidf").show(truncate=False)

🔹 Step 3: Compute Similarity Score
Now that we have TF-IDF vectors, we can compute similarity between resumes and job descriptions using Cosine Similarity.
🔹 Code: Compute Cosine Similarity
from pyspark.ml.linalg import DenseVector
from pyspark.sql.functions import udf
from pyspark.sql.types import DoubleType

# Cosine Similarity Function
def cosine_similarity(vec1, vec2):
    dot_product = float(vec1.dot(vec2))
    norm1 = float(vec1.norm(2))
    norm2 = float(vec2.norm(2))
    return dot_product / (norm1 * norm2) if norm1 and norm2 else 0.0

cosine_similarity_udf = udf(cosine_similarity, DoubleType())

# Compute similarity score
df = df.withColumn("similarity_score", cosine_similarity_udf(df["resume_tfidf"], df["job_desc_tfidf"]))
df.select("resume", "job_desc", "similarity_score").show(truncate=False)
✅ What this does:
	•	Computes a similarity score (0 to 1) between resumes and job descriptions.
	•	Higher scores mean better matches.

🔹 Step 4: Train a Machine Learning Model
Since we now have a similarity score, let's train a machine learning model (Random Forest) to learn patterns and predict a job match score.
🔹 Code: Train a Machine Learning Model
from pyspark.ml.regression import RandomForestRegressor
from pyspark.ml.feature import VectorAssembler
from pyspark.ml.evaluation import RegressionEvaluator

# Prepare Feature Vector
assembler = VectorAssembler(inputCols=["similarity_score"], outputCol="features")
df = assembler.transform(df)

# Train-test split
train_df, test_df = df.randomSplit([0.8, 0.2], seed=42)

# Train the Model
rf = RandomForestRegressor(featuresCol="features", labelCol="match_score")
model = rf.fit(train_df)

# Make Predictions
predictions = model.transform(test_df)
predictions.select("resume", "job_desc", "match_score", "prediction").show()
✅ What this does:
	•	Trains a Random Forest model on resume-job similarity data.
	•	Predicts a job match score (0-100).
